## ۲) پوشش واقعی

- **مسیرها:** همهٔ ۸ مسیر عمومی و ۲۴ مسیر ادمین در `routes.spec.ts` بازدید خودکار شدند؛ هر مسیر
  ادمین با **عنوان h1 اختصاصی خودش** assert می‌شود، نه فقط پوستهٔ layout. `/` نیز پس از علامت‌زدن
  intro به‌عنوان دیده‌شده، واقعاً `HomePage` را باز می‌کند. هیچ مسیری به login برنگشت و هیچ
  uncaught error ثبت نشد. `/order/:code` نامعتبر، `/staff/password`، `/staff/login` و ۴۰۴ هم پوشش دارند.
- **نقش‌ها:** cashier / waiter / barista / kitchen؛ مسیریابی مجاز و ممنوع هر نقش assert شد.
  API نیز برای cashier روی `/users` قطعاً ۴۰۳ می‌دهد؛ پنهان‌کردن منو تنها خط دفاع نیست.
- **کاتالوگ:** ساخت دستهٔ واقعی از UI + reload؛ **انبار:** ساخت ماده اولیه در ماژول فعال؛
  **رزرو:** بازشدن فرم متصل به سرور و بستن آن.
- **مسیر پول:** سفارش مشتری → تأیید/آماده/سرو → پرداخت در صندوق → رسید در صف چاپ →
  بستن و آزادشدن میز، با بررسی مستقیم `orders`/`payments`/`print_jobs`/`table_sessions`.
- **بازی‌ها:** ۳۸/۳۸ playable؛ ۷۶ تست قواعد و ۶۵ تست رندرر. دو گوشی روی یک میز، نوبت و حرکت
  هم‌زمان، و سوکت ۴۴۰۱/۴۴۰۰ در تست‌ها پوشش دارند.
- **۳۶۰px:** مسیرهای کلیدی (`/`، منو، بازی، داشبورد، سفارش‌ها، صندوق، میزها، کاتالوگ) بدون
  سرریز افقی؛ صفحهٔ کاتالوگ با داده و داشبورد حاوی سفارش تسویه‌شدهٔ `money-flow` نیز آزمون شد.
