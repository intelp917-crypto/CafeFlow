# ۷. سیستم طراحی UI/UX

## هویت بصری

| نقش | رنگ |
|---|---|
| اصلی (اسپرسو) | `#aa472b` — `brand-500` |
| ثانویه (سنگ) | `#96a09f` — `sec-300` |
| بوم | `#f7f4f0` — `canvas` |
| سطح | `#ffffff` — `surface` |
| خط | `#e8e2db` — `line` |
| متن | `#241f1c` — `ink` |
| متن کم‌رنگ | `#6f6862` — `muted` |

توکن‌ها در `apps/web/src/styles.css` با `@theme` تعریف شده‌اند؛ کامپوننت‌ها فقط از نام توکن استفاده می‌کنند، نه از مقدار خام.

## تایپوگرافی

- فونت: **Vazirmatn** (نسخه variable، به‌صورت لوکال از `@fontsource-variable/vazirmatn` — بدون CDN).
- `line-height` پایه ۱.۷ برای خوانایی فارسی؛ عنوان‌ها `tracking-tight`.
- اعداد: کلاس `.num` با `tabular-nums` و `unicode-bidi: plaintext` تا ارقام فارسی/تاریخ جابه‌جا نشوند.

## RTL واقعی، نه آینه‌شده

- `index.html` با `lang="fa" dir="rtl"`.
- **فقط خصوصیات منطقی**: `ms/me`, `ps/pe`, `start/end`, `border-s/e`, `text-start/end`.
- آیکون‌ها و چیدمان از ابتدا برای راست‌به‌چپ طراحی شده‌اند؛ هیچ `transform: scaleX(-1)` سراسری وجود ندارد.
- سوییچ‌ها و نوارهای پیشرفت با `start` جابه‌جا می‌شوند.

## ارقام و تقویم

- حالت ارقام از تنظیمات (`fa` یا `latin`) خوانده می‌شود؛ `formatRial` و `formatJalali` در `packages/shared` این حالت را اعمال می‌کنند.
- همه تاریخ‌ها با `formatJalali` (تقویم جلالی، منطقه تهران) نمایش داده می‌شوند.
- ورودی کاربر با `parseAmountInput` و `toLatinDigits` نرمال می‌شود؛ «۱۲٬۵۰۰» و «12,500» یک مقدارند.

## کامپوننت‌ها (`packages/ui`)

`Button` (۵ گونه، ۳ اندازه، حالت بارگذاری)، `Card`/`CardHeader`/`CardBody`/`StatCard`،
`Input`/`Textarea`/`Field` (برچسب + راهنما + خطا)، `Badge`/`Alert`، `EmptyState`/`ErrorState`،
`PageHeader`، `Switch` (با `role="switch"`)، `Modal` (Escape و کلیک پس‌زمینه)، `Spinner`، `DataTable`.

قواعد:

- هر عنصر تعاملی حداقل ۳۶–۴۴ پیکسل ارتفاع touch target دارد.
- همه حالت‌ها پوشش داده شده‌اند: بارگذاری، خالی، خطا، موفقیت، هشدار.
- `focus-visible` با حلقه ۲ پیکسلی و رنگ برند.
- `prefers-reduced-motion` در CSS پایه انیمیشن‌ها را غیرفعال می‌کند.

## زبان و پیام‌ها

- تمام متن قابل مشاهده فارسی است: برچسب، دکمه، خطا، وضعیت خالی.
- پیام‌های خطای API فارسی و قابل نمایش‌اند؛ کد خطا (`code`) انگلیسی و پایدار است.
- کد منبع، نام متغیرها، مسیرها و لاگ‌ها انگلیسی می‌مانند.

## دسترس‌پذیری

- ساختار عنوان‌ها (`h1` در `PageHeader`، `h2` در `Card`) و `caption` پنهان برای جدول‌ها.
- `aria-invalid` روی ورودی خطادار، `aria-label` روی سوییچ و دکمه‌های آیکونی.
- کنتراست متن روی `canvas`/`surface` بالاتر از ۴.۵:۱ برای متن اصلی.

## نقشه راه بصری

انیمیشن قهوه (Three.js + anime.js) در فاز ۲ به‌صورت chunk مستقل بارگذاری می‌شود؛ نسخه سبک برای دستگاه ضعیف و احترام به `prefers-reduced-motion` الزامی است.
